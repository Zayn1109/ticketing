# 架構決策紀錄（ADR）

每份 ADR 記錄一個重要的技術決定：當時的背景、選了什麼、為什麼、付出什麼代價。

## 慣例

- 檔名：`NNNN-簡短英文描述.md`，編號遞增、不重複使用
- 寫完不改內容；決定改變時寫一份新的 ADR，並把舊的狀態改為「已被 NNNN 取代」
- 狀態：`提議中` / `已採納` / `已棄用` / `已被 NNNN 取代`
